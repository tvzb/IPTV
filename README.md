# 📺 IPTV 五步法全自动采集、台标OCR识别纠错与稳态测速引擎

专为国内 **TVBox（及各类 Android TV 电视盒子）** 打造的 Serverless 全自动直播源工作流。基于 GitHub Actions 运行，支持多页自由深度采集、多切片稳态真视频校验、视频画面左上角台标 OCR 智能识别自动纠错、央卫视同源后缀规律智能裂变，以及 **1080P H.264 国内直连优先排序**。

---

## ✨ 核心特性

### 1. 🔍 搜索结果多页自由采集（拒绝同仓库历史归档刷屏）
* **自由页数选择**：支持在运行工作流时自由选择采集搜索结果的页数（默认 `1` 即首页 20 条；选 `2` 采集第 1、2 页共 40 条；最高支持前 `5~10` 页）。
* **同仓库自动折叠去重**：针对 GitHub 代码搜索中单个仓库多条历史日期归档霸屏的问题，自动按仓库去重折叠，确保每一条名额都来自不同的独立仓库，并自动穿透预览框读取 `Raw` 纯文本全量直播源[cite: 2]。

### 2. 👁️ 视频画面左上角台标 OCR 识别与自动纠错
* **真画面截图识别**：在测速下载 `.ts` 视频切片时，直接通过 `ffmpeg` 从内存提取视频首帧并裁剪左上角（兼容右上角）台标区域，配合 **RapidOCR (ONNXRuntime)** 与 OpenCV 多阈值图像增强（2倍超分 + 高亮反色二值化）识别台标文字。
* **挂羊头卖狗肉自动改正**：同时结合 MPEG-TS 流内嵌的 `SDT (service_name)` 节目表元数据。若原列表标记为 `CCTV-1`，但实际播放画面左上角台标识别为 `CCTV-5`，系统将自动把该源改正并归类到 `CCTV-5 体育` 名下。

### 3. ⚡ 多切片连续稳态测速（彻底解决“前排源卡顿”与“黑屏几秒跳台”）
* **真视频关键帧强校验**：通过 `ffprobe` 严格检验视频轨编码、像素格式（拦截导致电视盒子硬解黑屏的 10-bit `yuv420p10le` / `yuv422p` 等怪异格式）以及真实视频数据包，彻底消灭“有声无画”和“黑屏几秒自动切台”的假流。
* **多切片防断流检测**：不再只测单切片首包突发缓存，而是强制连续拉取最后 **2~3 个不同切片**（最高采样 1.2MB），自动拦截单切片循环闪退源与“第1秒极快、第2秒断流”的假高速源。
* **TVBox 流畅度黄金排序**：打破海外服务器测速对国际 CDN 的虚高偏见，按 **`1080P H.264 (AVC) > 720P H.264 > HEVC/4K > 标清`** 结合 **国内直连亲和度** 与 **同 IP 交错打散** 策略排序，确保排在每个频道第 1 位的源在电视盒子上 100% 秒开不卡顿。

### 4. 🧬 央卫视同源后缀智能裂变与二次增量测速
* **精准同构裂变**：以第一轮测速通过的高速稳定源为种子，自动按规律推导同服务器下的全套频道（如 `cctv1hd.m3u8` 自动裂变 `cctv1hd ~ cctv17hd.m3u8`；`dfwshd.m3u8` 自动裂变 `jxwshd`、`hnwshd` 等 30 个省级卫视，完整保留 `hd/sd/fhd` 等画质尾缀）。
* **严格增量去重**：第五步仅对第四步裂变新生成的未知地址进行二次测速，第一轮已测过的地址绝不重复测速[cite: 2]。

## 🔄 五步工作流架构

```text
[第一步：多页全量搜索采集]
  ├─ 按设定页数 (1~5页) 搜索最新月份直播源 + 国内高活性 Raw 补充矩阵
  └─ 同仓库去重折叠 -> 打开文件预览框 -> 点击 Raw 提取全量纯文本源
         ↓
[第二步：深度清洗与配额去重]
  ├─ 剔除 $ 尾缀信息，彻底拉黑 /rtp/、/udp/ 组播假源、.swf、纯音频及一次性动态 Token 源
  └─ 全局 HTTP 严格去重，单频道限额前 65 条候选（同 IP 端口限 5 条）并归档至 raw_sources.txt
         ↓
[第三步：初次多切片稳态测速 + 左上角台标 OCR 纠错]
  ├─ 模拟国内 TVBox (okhttp/3.15 + 国内 IP 头) 连续拉取 2~3 个 TS 切片测算稳态速度
  ├─ ffprobe 校验视频关键帧与像素格式 + RapidOCR 识别画面左上角台标自动纠正错位频道
         ↓
[第四步：央卫视智能后缀裂变]
  ├─ 基于第三步验证通过的高速种子源，裂变推导 CCTV 1~17 及 30 个省级卫视同源地址
  └─ 自动过滤第一轮已测过的 URL，仅保留全新候选地址
         ↓
[第五步：裂变新源二次测速 + 黄金流畅度排序导出]
  ├─ 对裂变新源执行同等标准的稳态测速与台标 OCR 校验
  └─ 合并两轮达标源 -> 按「1080P H264 + 国内直连 + 多切片稳态速度 + 同IP交错」排序 -> 输出 live.txt / live.m3u
