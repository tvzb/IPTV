# 电视直播源专属定制与全自动化工作流平台 (IPTV Custom Studio)

一套专为开源社区和电视爱好者设计的自动化直播源采集、清洗、测速与订阅工作流系统。支持 **网友 Fork 自由定制分类与频道**、**双工作流解耦**、**支持 M3U 与 TXT 双输入与双输出**、**按流畅网速阈值不限数量筛选**，并配备可视化定制网页面板。

---

## 核心架构设计

### 1. 双工作流解耦架构
- **工作流 1：全网大采集与标准化清洗 (`harvest.yml` -> `harvester.py`)**
  - **职责**：专门负责抓取、归一化、去重与裂变。
  - **搜索面**：全网 16 大每日同步高星源矩阵 + GitHub Topic 活跃仓库（`topic:iptv`, `topic:tvbox`）+ 优质 IP:Port 全局反查 + 种子规律裂变。
  - **产物**：输出全量纯净候选源池 `raw_sources.txt`（彻底去除所有 `$` 符号及后置文字）。
- **工作流 2：TVBox 原生测速与达标优选 (`speedtest.yml` -> `speedtester.py`)**
  - **职责**：自动读取待测源池（兼容 TXT 与 M3U 双输入，支持采集输出的 `raw_sources.txt`，也支持网友自定义粘贴导入的任何源列表）。
  - **测速机制**：采用 TVBox 原生内核请求头（`okhttp/3.12.1`）与多级索引递归解析，防止海外机房误杀国内好源。
  - **按速度门槛不限数量保留**：默认保留测速 $\ge 300\text{ KB/s}$（可自主调节）的流畅播放源，**不限数量，达标越多越好**，按网速从高到低严格排序。
  - **双格式产物**：同步生成并在仓库提交 `live.txt`（电视盒子专用）与 `live.m3u`（主流播放器专用）。

### 2. 可视化定制面板 (`index.html`)
- 内置开箱即用的单页 Web 应用，直接托管在 GitHub Pages（例如 `https://<用户名>.github.io/IPTV/`）。
- **功能特性**：
  - **分类管理**：支持默认的“央视频道”、“卫视频道”，支持任意新建自定义分类（如“我的最爱”、“体育专区”）。
  - **加减频道**：从左侧预置总库中一键点击 `+` 注入到目标分类中，随时移除不想要的频道。
  - **拖拽/上下排序**：自由调整各分类中的频道换台顺序。
  - **粘贴自有直播源**：内置专属文本框，可直接粘贴已有直播源，支持**一键清洗去除 `$` 字符**、**纯前端 TXT ⇄ M3U 格式秒转**。
  - **一键导出配置**：一键导出 `channels.json`，提交进仓库即可让工作流完全按照你的个性化列表进行采集测速！
  - **云端一键直连**：支持填入 GitHub Token 在网页端直接遥控触发 Actions 工作流。

## 目录结构

```text
IPTV/
├── .github/
│   └── workflows/
│       ├── harvest.yml       # 工作流 1：全网大采集与清洗
│       └── speedtest.yml     # 工作流 2：TVBox 测速与优选 (生成 live.txt & live.m3u)
├── index.html                # 可视化定制 WebApp（托管在 GitHub Pages 供外部访问）
├── channels.json             # 用户自定义分类与频道排序配置文件
├── config.py                 # 核心配置、拼音映射、种子裂变算法、双格式输出支持
├── harvester.py              # 工作流 1 采集执行脚本
├── speedtester.py            # 工作流 2 测速与双格式导出脚本
├── requirements.txt          # Python 异步并发依赖
└── README.md                 # 项目说明文档
